# Book_Store_Sql_Analysis
I have develop Book Store Data Analysis project using SQL Server, he objective of this project is to analyze books, customers, and orders to understand sales performance, customer purchasing behavior, book inventory, genres, authors, and revenue.The project demonstrates the use of SQL for extracting, filtering, aggregating, and analyzing relational business data.
### Tools & Technologies
- SQL Server Management Studio (SSMS)
- GitHub

<a href="https://github.com/saymakhan0611/Book_Store_Sql_Analysis/tree/main/Dataset">Dataset</a>
### Database Structure
The project uses three main tables:
1. Books: It Contains information about books available in the bookstore.
2. Customers: It Contains customer information.
3. Orders: It Contains information about customer orders.

### Project Objectives
The main objectives of this project are:
- Analyze bookstore inventory
- Identify expensive and low-stock books
- Analyze book genres
- Analyze customer orders
- Calculate total revenue
- Identify frequently ordered books
- Analyze sales by genre and author
- Identify high-spending customers
- Calculate remaining book stock after orders
